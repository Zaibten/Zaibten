<details open>
<summary><b>🔎 SelectAITool.com — Making thousands of AI tools actually findable</b></summary>
<br/>

| | |
|---|---|
| **Problem** | Users needed to discover the right AI tool out of a large, growing catalog — simple keyword search wasn't cutting it. |
| **Approach** | Built a React/Node.js/MongoDB platform with Algolia-powered search, then layered a custom multi-pass fuzzy search using Levenshtein scoring to catch typos and near-matches. Added an Excel-based bulk upload pipeline so new tools could be added fast, plus profession-based UI modals for filtering. |
| **Result** | A live, production directory at **selectaitool.com** with fast, forgiving search and a content pipeline that doesn't require manual entry per tool. |

</details>

<details>
<summary><b>👷 LabourHub — Rebuilding a backend to survive serverless</b></summary>
<br/>

| | |
|---|---|
| **Problem** | The existing backend wasn't compatible with serverless deployment, and the admin experience needed real, live data. |
| **Approach** | Rewrote the Node.js backend for full Vercel compatibility — serverless routing, cached MongoDB connections, removed incompatible packages. Built an admin dashboard with real-time Chart.js analytics and paginated tables, fixed Google Maps rendering issues, corrected HTTP semantics (proper 404s for empty lists), and added Nodemailer-based agreement emails plus Expo push notifications. |
| **Result** | A stable, serverless-ready platform with a working admin dashboard, reliable notifications, and a backend that scales the way Vercel expects it to. |

</details>

<details>
<summary><b>🔄 Code Sync — A sync app with an admin panel that doesn't feel bolted on</b></summary>
<br/>

| | |
|---|---|
| **Problem** | Needed a Flutter app that reliably syncs and manages files/data, with an admin panel that's actually pleasant to use — not an afterthought. |
| **Approach** | Built the Flutter client alongside a Node.js/Vercel backend, handling MongoDB saving, local file management, and auto-refresh. Designed a polished, animated admin panel with bcrypt-secured auth, then hardened the Vercel deployment against connection drops, model re-registration issues, and session-handling bugs. |
| **Result** | A smooth, animated admin experience backed by a serverless deployment built to stay stable under real usage. |

</details>
