```mermaid
flowchart LR
    A[User Input] --> B[App Layer<br/>Flutter / React / Next.js]
    B --> C[API Layer<br/>Node.js + Express]
    C --> D{AI Layer}
    D -->|LLM reasoning| E[OpenAI / Hugging Face APIs]
    D -->|Custom models| F[TensorFlow / PyTorch]
    C --> G[(MongoDB)]
```
